# Changelog

## [1.0.0] - 2026-11-05
### Added
- Initial production release of **CPVP Optimizer** for Minecraft Java Edition `1.21.11` (Fabric).
- Implemented all 13 optimizer modules across Combat, Interaction, Performance, Network, and Server categories.
- Added Vanilla Minecraft UI (`OptimizerScreen`, `SettingsScreen`) with Left-Click toggle, Right-Click settings, smooth mouse-wheel scrolling, and draggable proportional scrollbar.
- Added mandatory Client + Dedicated Server split build (`CPVP-Optimizer-Client.jar` and `CPVP-Optimizer-Server.jar`) and versioned `CustomPayload` telemetry protocol (`v1`).
